# Security Policy

## Supported Versions

Security fixes are prioritised for the latest version of Vertex on the default branch. Older versions may not receive security updates.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues or pull requests.

Use GitHub's private vulnerability reporting feature on the repository's **Security** tab, if it is enabled. If private vulnerability reporting is unavailable, contact the repository owner privately through GitHub and include the repository name and a concise description of the issue.

When reporting a vulnerability, include:

- The affected version or commit, if known.
- The impact and conditions required to reproduce the issue.
- Clear reproduction steps or a proof of concept that does not expose real user data.
- Any suggested mitigation, if available.

Please allow maintainers a reasonable amount of time to investigate and prepare a fix before making a vulnerability public. Do not disclose the issue publicly until a coordinated disclosure has been agreed.

The project does not currently publish a guaranteed response or remediation time.
