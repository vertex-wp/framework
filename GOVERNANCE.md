# Governance

Vertex is an open-source project maintained by its repository owner.

## Project Leadership

The project owner is responsible for the technical direction, roadmap, releases and final decisions about changes to the framework.

The owner may invite contributors to help review, maintain or develop parts of the project. Such responsibilities are granted explicitly and may be adjusted as the project evolves.

## Contributions and Decision-Making

Contributions are welcome in accordance with [CONTRIBUTING.md](CONTRIBUTING.md).

- Bug reports and feature proposals should be raised through the repository's issue templates.
- Substantial changes should be discussed before implementation.
- Pull requests are reviewed for correctness, maintainability, compatibility, security and alignment with the project's scope.
- The maintainer makes the final decision to accept, request changes to or close a contribution.
- Technical discussions should remain respectful and focused on the project's long-term quality.

Community feedback is considered in good faith, but participation does not imply decision-making authority or a commitment to implement a proposal.

## Releases

The maintainer is responsible for preparing and publishing releases. Release notes should communicate user-visible changes, compatibility considerations and relevant upgrade guidance.

## Changes to This Policy

This governance model may evolve as the project and its contributor community grow. Material changes will be documented in this file.
