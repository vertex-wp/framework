# Getting Support

Vertex is an open-source framework maintained through this GitHub repository.

## Where to Ask

- **Bug reports:** Open an issue using the Bug Report template. Include a minimal reproduction and the relevant PHP and WordPress versions.
- **Feature proposals:** Open an issue using the Feature Request template. Explain the use case and why the capability belongs in the framework.
- **Usage questions:** Search the README and existing issues first. If the question reveals a documentation gap or a reproducible defect, open an appropriately scoped issue.

## What to Include

Provide enough context to understand the problem:

- Vertex version or commit.
- PHP and WordPress versions.
- Relevant framework API usage.
- Expected and actual behaviour.
- A minimal, reproducible example where possible.

Remove passwords, access tokens, personal information and production data before sharing logs or code.

## Scope

Support is provided on a best-effort basis. The project does not provide paid support, consultancy or guaranteed response times. Please do not use the issue tracker for general WordPress support or requests unrelated to Vertex.

For security concerns, follow [SECURITY.md](SECURITY.md) and do not create a public issue.
